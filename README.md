# Ценники

Приложение для ценников, прайс-листов и печатной продукции. Работает прямо в браузере iPhone, без Claude и без интернета после первого открытия.

## Как открыть на iPhone

1. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, выберите ветку с файлом `index.html` и папку `/ (root)`, нажмите **Save**.
2. Через минуту появится адрес вида `https://<логин>.github.io/cenniki/`. Откройте его в **Safari**.
3. Нажмите **Поделиться → На экран «Домой»**. Появится значок «Ценники», приложение откроется на весь экран и будет работать без интернета.

## Где хранятся данные

Изделия и настройки хранятся в памяти Safari на этом iPhone. Чтобы не потерять их, время от времени делайте резервную копию: **Мои изделия → Резервная копия → Скачать** (файл `.json` можно сохранить в «Файлы» и потом загрузить обратно).

## Печать и файлы

Кнопки PDF, PNG, SVG и ZIP открывают меню iPhone «Поделиться»: оттуда можно сразу **Напечатать** (AirPrint), **Сохранить в «Файлы»** или отправить в мессенджер.

Функции «Заполнить из текста» с помощью ИИ работают только внутри claude.ai, в этой версии они скрыты.
